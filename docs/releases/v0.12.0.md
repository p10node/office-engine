## Word, Excel and PowerPoint 97-2003, RTF and OpenDocument

- `.doc` / `.dot`, `.xls` / `.xlt`, `.ppt` / `.pot` / `.pps`, `.rtf`, `.odt` / `.ott` / `.fodt`, `.ods` / `.ots` / `.fods` and `.odp` / `.otp` / `.fodp` files open **editable**, from any `src` and from File → Open. The worker converts them in memory to the Word, Excel or PowerPoint file the views show, and Save writes that file (`report.doc` is saved as `report.docx`, `budget.ods` as `budget.xlsx`); the original is never overwritten. The bar shows a `DOC` / `XLS` / `PPT` / `RTF` / `ODT` / `ODS` / `ODP` badge; *Document details* says "Word 97-2003 document, opened as Word document".
- The format comes from the file's bytes, so a `.doc` that is really RTF, an Excel stream outside a compound file, or a file without a name opens too.
- Word 97-2003: styles, character and paragraph formatting, lists, tables (merged cells, nested tables), sections, headers and footers, footnotes and endnotes, comments, bookmarks, tracked insertions / deletions, fields, pictures, text boxes, shapes and WordArt text.
- Excel 97-2003 (also Excel 5.0 / 95): every sheet, values, cell formats, number formats, merged cells, sizes, hidden rows / columns, outlines, frozen panes, formulas (shared, array, names, 3-D references) with their last values, defined names, page setup, hyperlinks, comments.
- PowerPoint 97-2003: masters and title masters, color schemes, backgrounds, about 190 shape types, freeforms, fills, lines, shadows, groups, tables, text with bullets and numbering, pictures, hidden slides, footers, speaker notes and comments.
- RTF: every code page (also Japanese, Chinese and Korean), styles, lists (also the WordPad kind), tables, sections, headers and footers, footnotes and endnotes, links, bookmarks, tracked changes, pictures, text boxes.
- OpenDocument text, spreadsheet and presentation (also templates and flat XML): styles, lists, tables, pictures, text boxes, page styles, headers and footers, notes and comments; formulas translated to Excel's syntax with their last values; master pages, custom shapes, fills, lines and connectors, tables and speaker notes.
- Not converted yet: EMF / WMF pictures (kept in the file, shown as a placeholder), charts and embedded objects (their preview picture when there is one), animations, conditional formats and data validation. Password-protected files, Word 6.0 / 95, Excel 2.x-4.0, PowerPoint 95 and OpenOffice.org 1.x files give an error saying so. See [features](../features.md) for the full lists.

## Documents

- A section break now applies where its section starts, as in Word: a continuous section after a new-page one stays on the same page, and a new-page section after a continuous one starts a page.

## Formulas

- `HYPERLINK` (135 functions): shows its friendly name, or the link.

For integrators: `doc.info.converted` is `'doc'` / `'xls'` / `'ppt'` / `'rtf'` / `'odt'` / `'ods'` / `'odp'` for a converted file; `onSave(blob, name)` receives the `.docx` / `.xlsx` / `.pptx`. `src` and File → Open accept the extensions above. No new dependency.
