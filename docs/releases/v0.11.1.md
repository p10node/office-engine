## Release

- The same code as v0.11.0, published for every package. In v0.11.0 only `@p10node/office-engine` reached npm: the SDK packages (`@p10node/diagram`, `mermaid`, `plantuml`, `graphviz`, `markdown`) were refused by npm trusted publishing, and stayed at 0.9.0. They come to this version with v0.11.0's changes (see those notes) and v0.10.0's.
- The release workflow can publish a released tag again by hand (Actions → Release → Run workflow from `main`, with the tag), for packages still missing on npm; re-running a release run after it pushed the version commit works again.
