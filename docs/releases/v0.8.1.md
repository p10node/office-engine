## Security

- A link in a document can no longer run script in the page. DOCX links (text and pictures) and PPTX text links were used as the link target exactly as written in the file, so a crafted file with a `javascript:` or `data:` link could run code in the host page when the link was clicked. React 19 blocks `javascript:` links itself, React 18 does not, and `data:` links stayed clickable with either (most browsers refuse to open them, not all). Now only `http(s)`, `mailto`, `tel`, `sms`, `ftp(s)`, relative and in-document (`#bookmark`) links are clickable; any other target shows as plain text. The scheme is read the way a browser reads it, so disguises like `java<tab>script:` or leading control characters are caught.
- The same rule applies to the web page and Markdown exports, and to links imported from HTML and Markdown (File → Open, paste, an `.html` / `.md` `src`); those used to drop only `javascript:`.
- Files are not changed: the links stay in the document and in what is saved.

Upgrading is recommended for every host that shows files from people it does not fully trust, especially on React 18.
