## Dark mode

- `theme="dark"`, or `"auto"` to follow the OS / browser setting (`prefers-color-scheme`): bars, toolbar, menus, dialogs, sheet headers and tabs, thumbnails and popovers darken. Pages, slides and cells keep the colors the document gives them.
- Script embed: `<office-viewer theme="dark">` and `mount(el, { theme: 'dark' })`.
- The palette is CSS variables on `.de-root`; add `de-dark` to the root element when composing your own UI from the views.
