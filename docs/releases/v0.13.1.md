## Security: a crafted file could make the browser request an address

- Opening a crafted DOCX, XLSX or PPTX file made the browser request an address chosen by the file's author, who then learned the reader's IP address and when the file was opened. No script ran. A color in the file was given to CSS as written, and `fff url(https://…)` is a valid `background`. Every version up to v0.13.0 is affected: hosts that show files from other people should update.
- Colors are now checked where they are read (hex digits only: DrawingML `srgbClr` / `sysClr`, theme colors, sheet colors, a workbook's own palette, the fill and outline of a DOCX text box) and again where they are used (CSS `background`, SVG `fill` / `stroke`, the HTML export): a color, or a gradient of colors, and nothing more.
- The same goes for the colors that reach a view another way: the color of a collaboration peer, which a hub relays to everyone in the room, and the colors of an edit. An edit's color is also written into the file's XML only when it is hex digits.

## Hardening

- DOCX: *Open link* in the context menu opens web, mail and phone links only, like a click on the link. It is disabled for any other target (`javascript:` …).
- Packages: a ZIP that names a part twice (also by case) is refused. So are more than 200,000 files, a part that unpacks to more than 1 GB (16 GB for sheet data and a document's body, which are streamed), and a directory or an entry lying outside the file. The size an entry announces is no longer what is allocated.
- XML nested deeper than 1,024 elements is refused with a message, by every parser. It used to run out of stack somewhere later.
- Collaboration: a DOCX `call` operation is run by the clients that receive it only when it names one of the shared document-level edits (`docx.style`, `docx.styleSet`, `docx.page`, `docx.hf`), with arguments of their shape. It used to run any worker method a peer named.
- A file naming something every object inherits (`constructor`, `__proto__`, `toString` …) where it names a preset color, a border style, an alignment or a highlight showed a blank document, or failed to open. The lookups no longer see inherited keys.

These were reported privately, with a clear reproduction. Thank you.

For integrators: in a shared room every participant should run this version, since an older client still runs any `call` a peer sends. A file that names a part twice opened before and is refused now. `UserInfo.color` takes a CSS color (hex, `rgb()` / `hsl()`, a color name); anything else is replaced by one of the palette.
