## Spreadsheets: line breaks inside a cell

- `Shift+Enter` and `Alt+Enter` (`Option+Enter` on a Mac) break the line while a cell is edited, in the cell and in the formula bar. `Alt+Enter` used to depend on the browser breaking the line by itself; `Shift+Enter` used to commit and move up. `Enter` alone still commits and moves down, and `Shift+Enter` on a cell that is not being edited still moves up.
- Text entered with line breaks shows as typed: the cell is set to wrap and its row grows to fit the lines, as in Excel. It used to stay on one row's height, spilling over the cells above. One undo takes back the text, the wrap and the row height; the saved file keeps all three.
- The formula bar keeps the line breaks of a cell. It was a one-line field that dropped them, so editing such a cell there joined its lines. It shows one line at a time, following the caret.

The row grows for the line breaks typed, not for lines that wrap because the column is narrow. A merged cell and a formula written over several lines leave the row height alone.

For integrators: the result of `xlsx.set` can now carry `styles` and `layout` (a derived wrap style, the grown row), as `xlsx.format` and `xlsx.sheetOp` results do. In a shared workbook every participant should run this version: an older one replays such an edit without the wrap and the row height.
