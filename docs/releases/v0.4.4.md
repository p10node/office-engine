## Fixes

- docx: a paragraph edited again right after its style or list changed keeps up with that change. The text already there kept its old look when the next edit came before the worker had answered: for the author typing straight after picking a style and, in shared rooms, for everyone replaying both edits back to back (newcomers, history). The file was right; only the screen was not, until the document was reopened.
- docx, shared rooms: a paragraph between two tables is no longer lost for one editor. When an editor joined it to the paragraph above while someone else put a table between the two, the next change to arrive could leave that editor without the paragraph and without what others then typed in it: the documents no longer matched.
- docx, shared rooms: Undo only takes back typing in the paragraph it was typed in. Typing in two paragraphs within 1.5 s counted as one step when a collaborator's edit had moved the second one to where the first was; Undo then replaced it with an old copy of the first.
- docx, shared rooms: undoing a table insert no longer brings back the paragraph before the table when someone joined it to another one meanwhile. It showed on screen, its text there twice, but was not in the saved file, nor were later edits to it.
